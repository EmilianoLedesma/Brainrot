# Coffee: current Brainrot versus Lemo-Opuscar

A local, unpublished comparison requested on 2026-10-27. Both edits reuse one
original **English, Grounded (0/100)** script generated by `brainrot.script`, its
explicit storytelling skill, and one `brainrot.tts` Guy narration with word times.
The measured voice is **128.5025 seconds**; the script and title total **331 words**.

## What is integrated

`run.py` connects **real Brainrot generation and speech** to both renderers.
The baseline invokes the production entry point without changing its behavior;
it observes the planning result to save the exact props used for review. The
Lemo plan is a separate Codex call that explicitly receives pinned Lemo directing
and style guides, then validates exact cue phrases against the spoken words.
Adjacent shots are merged to avoid unreadably short headings.

The second film uses the actual upstream **isometric engine**, **frame renderer**,
**reading-time checker**, **event exporter** and **procedural sound library**.
Its original coffee-specific drawing code is in `film/`. This is a directed
coffee prototype with a reusable local bridge, not arbitrary-topic unattended
animation, a dashboard mode, or an installed global plugin. Several shot-plan
details are adapted to the available coffee scene vocabulary rather than
executed as free-form model-written code. No queue, database or publisher runs.

The voice and timeline are identical; B's final adds sound effects. Its voice-only
control preserves the visual experiment without those effects. Caption grouping
and layout differ as part of the two edits. Normal mastering uses Brainrot's
−16 LUFS / −1.5 dBTP target. It intentionally overrides Lemo's default duration,
landscape canvas, voice engine and loudness to fit this comparison.

## Reproduce

First bootstrap Brainrot and sign in to Codex on this computer. Keep the selected
provider: the scripts explicitly use `codex`, never Claude or an API fallback.
Generation needs network access and uses the CLI subscription; edge-tts needs
network access too. The process-local model timeout is 900 seconds for this
experiment, leaving normal project configuration untouched.

```sh
python experiments/coffee-comparison/fetch_lemo.py
npm ci --prefix experiments/coffee-comparison
uv venv experiments/coffee-comparison/.venv --python 3.14
uv pip install --python experiments/coffee-comparison/.venv --require-hashes -r experiments/coffee-comparison/requirements.lock

uv run --locked python experiments/coffee-comparison/run.py prepare
uv run --locked python experiments/coffee-comparison/run.py baseline
uv run --locked python experiments/coffee-comparison/run.py design
uv run --locked python experiments/coffee-comparison/run.py build-lemo
uv run --locked python experiments/coffee-comparison/run.py render-lemo
```

`build-lemo` saves real style frames and runs upstream readcheck before the full
render. It uses a local Edge/Chrome on Windows if present; otherwise install
Chromium with `npx --prefix experiments/coffee-comparison playwright-core install chromium`
or set `PLAYWRIGHT_CHROME` for this session. No specific user's path is saved.
Source changes should be followed by `build-lemo`; existing raw renders must be
archived before rendering the revised picture. Saved story/voice/final baseline
are reused, so remove or archive them deliberately only when you intend a new run.

Run the artifact checks with the experiment's Python (Windows shown; on Unix use
`.venv/bin/python`), and the browser check with `PLAYWRIGHT_CHROME` if needed:

```sh
experiments/coffee-comparison/.venv/Scripts/python experiments/coffee-comparison/verify.py
experiments/coffee-comparison/.venv/Scripts/python experiments/coffee-comparison/verify.py preview
uv run --locked python experiments/coffee-comparison/run.py playback
```

These checks do not establish audience retention or replace listening and watching
the film. Readcheck evaluates declared text bounds/durations, not every occlusion.
All particle/flow drawings are marked schematic; there are no measured yield
graphics or claims of a universal perfect coffee recipe. See [FACTS.md](FACTS.md),
[TREATMENT.md](TREATMENT.md) and [CREDITS](CREDITS).

## Recorded result — 2026-10-27

The actual baseline design call succeeded: eight scenes, four model-selected
devices. Lemo uses ten timed shots. Both main files are 1080×1920 at 30 fps,
H.264/AAC, and measure −16.03 LUFS. Baseline is 128.6 s / 9,439,867 bytes;
Lemo is 128.5 s / 8,966,817 bytes. Full decode, black-frame scan and upstream
reading-time checks passed. Final-file timeline sheets and 0.2-second boundary
strips were inspected. The files and source checks are recorded in the ignored
reports. No full production test suite was rerun because production code did not
change.
The synchronized player also passed complete normal-speed headless playback of
both final films, audio switching and restart, with no page or media errors after
fixing an interrupted-play race when changing audio sources.

B explains mechanisms with coffee-specific geometry, whereas A uses generic
words/cards. B still holds some compositions for long spoken passages and uses
simpler transitions than the Stupy Doo reference; it does not establish equivalent
visual quality, autonomous editing or improved retention. There is no claim of a
full sensory watch/listen by the agent.
